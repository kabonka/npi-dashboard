## NPI Dashboard 密码保护（Netlify Edge Function）
- 需求：限制 Dashboard 访问权限，不用前端 JS 密码（不安全）
- 方案：Netlify Edge Function + Basic Auth（免费，服务端验证）
- 已完成：
  - 创建 `netlify/edge-functions/basic_auth.ts`（读取环境变量 BASIC_USERNAME/BASIC_PASSWORD）
  - 创建 `netlify.toml`（配置 publish 目录和 edge function）
  - 已 commit + push 到 GitHub（commit bf651cf）
  - Netlify 会自动部署
- 待用户操作：
  - 在 Netlify Dashboard → Site configuration → Environment variables 中添加：
    - `BASIC_USERNAME` = 用户名
    - `BASIC_PASSWORD` = 密码
  - 然后 Deploys → Trigger deploy → Deploy site
- 安全说明：此方案为服务端验证，密码存在 Netlify 环境变量中，源代码看不到。但 HTTPS 下 Basic Auth 适合防普通访问，不适合极度敏感数据。
